# Referencias recomendadas — PostgreSQL for Everybody

Lista curada de material complementario para profundizar en cada curso. No reemplaza el contenido de Coursera — es apoyo transversal para las secciones "Apuntes" de cada semana.

## General / oficial (válido para toda la especialización)

- **[pg4e.com](https://www.pg4e.com/)** — sitio complementario gratuito de Dr. Chuck (Charles Severance), con slides en PDF y ejercicios que siguen el mismo temario que el curso de Coursera, módulo por módulo. Es la fuente más alineada posible porque la escribió el mismo instructor.
- **[PostgreSQL Official Documentation — Tutorial](https://www.postgresql.org/docs/current/tutorial.html)** — fuente primaria para sintaxis y comportamiento exacto de PostgreSQL (no genérico de "SQL").
- **"Learning SQL" (Alan Beaulieu, O'Reilly)** — libro clásico de fundamentos SQL/relacional; buen respaldo si algo del curso queda corto en explicación.

## Historia y fundamentos teóricos (Curso 1)

- E. F. Codd, *"A Relational Model of Data for Large Shared Data Banks"*, Communications of the ACM, 1970 — el paper fundacional del modelo relacional.
- Charles Severance, *["Elizabeth Fong: Creating the SQL Database Standards"](https://www.computer.org/publications/tech-news/computing-conversations/elizabeth-fong-creating-the-sql-database-standards)*, IEEE Computer, 2014 — perfil de la persona clave en la estandarización de SQL en NIST/ANSI, citada en el módulo 1.

## Texto, hashing y regex (Curso 2)

- **[Use The Index, Luke](https://use-the-index-luke.com/)** — guía práctica sobre índices SQL, útil para la semana de "Text in PostgreSQL".

## JSON / NLP / Python (Curso 3)

- **[PostgreSQL Docs — JSON Types](https://www.postgresql.org/docs/current/datatype-json.html)**
- **[PostgreSQL Docs — Full Text Search](https://www.postgresql.org/docs/current/textsearch.html)** — para ts_vector/ts_query del módulo 2.

## Arquitectura / NoSQL (Curso 4)

- **[Documentación oficial de Deno KV](https://docs.deno.com/deploy/kv/manual/)**
